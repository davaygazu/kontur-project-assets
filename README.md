# КОНТУР - изображения проектов

Отдельное хранилище фотографий, готовых цветовых вариантов, WebP, масок кровли и планировок.

- `kontur-83` - Контур 83
- `tihiy` - Тихий
- `kedr` - Кедр
- `istoriya` - История
- `izhora` - Ижора
- `gorizont` - Горизонт
- `leon` - Леон
- `kvartsi` - Квартси
- `istok` - Исток

Контур 83: 17 пробных цветов дерева с чёрной кровлей. Статус draft, не утверждено для публикации. Кедр: 17 цветов дерева с чёрной кровлей, PNG-исходники и WebP для компьютера и телефона. Зелёный вариант утверждён, остальные отмечены как черновики. Тихий: 17 цветов дерева с чёрной кровлей для каждого из двух вариантов дома. Зелёные кадры утверждены, остальные отмечены как черновики. Леон, Квартси, Исток и Горизонт: по 17 черновых цветов дерева с чёрной кровлей, WebP для компьютера и телефона. История: 17 черновых цветов фасада с исходной тёмной кровлей, WebP для компьютера и телефона. Цветовая серия Ижоры ещё не добавлена. Основной сайт не изменяется.
